# 产品需求文档 (PRD)

## 1. 产品简介
**产品名称**：人生三万天 (Life 30,000 Days)
**产品定位**：一款以“生命倒计时”为核心理念的自我管理与生活记录应用。
**核心价值**：通过直观展示生命剩余天数（以人生三万天为尺度），唤醒用户对时间的感知；并提供随笔记录与人际交集管理功能，帮助用户记录人生旅途中的点滴感悟与重要人物。

## 2. 目标用户
- 希望进行时间管理、提升自我时间观念的人群。
- 喜欢记录生活随笔、日记、心情感悟的用户。
- 重视人际关系，希望记录生命中重要“交集人员”的用户。

## 3. 核心功能需求

### 3.1 前端功能（用户端）
- **首页展示**
  - **生命倒计时**：基于用户设置的出生日期，计算并展示距离“三万天”的剩余天数。
  - **实时时钟**：展示当前时间的数字时钟。
  - **每日金句**：随机展示一条激励人心的名言金句。
- **用户认证与个人中心**
  - 注册与登录：支持邮箱/账号及密码注册登录。
  - 个人信息管理：可设置或修改个人基础信息及出生日期。
- **随笔/备忘录 (Memos)**
  - 发布随笔：支持纯文本及图片链接形式的记录，记录每日心情或重要事件。
  - 列表查看与管理：按时间倒序查看所有随笔，支持修改与删除。
- **交集人员 (Connections)**
  - 添加人员：记录在生命中相遇、产生交集的人，包括姓名、出生日期等。
  - 列表展示：查看所有交集人员列表，支持查看详情及删除操作。

### 3.2 后台管理功能（Admin Console）
*仅拥有 admin 权限的用户可访问*
- **用户管理**：查看系统中所有注册用户的信息，支持管理操作。
- **金句管理**：管理内置的“每日金句”库，可添加、编辑、删除金句。
- **系统设置**：支持更改系统全局配置，如切换金句的数据来源（本地数据库 / 在线 API）。

## 4. 非功能性需求
- **技术栈要求**：
  - 前端：Vue 3 + TypeScript + Vite + Tailwind CSS。
  - 后端：Node.js + Express + TypeScript。
  - 数据库：SQLite（轻量级、零配置、易于迁移，存放在独立的 `data` 目录）。
- **部署与运维**：
  - 必须支持 Docker Compose 容器化一键部署。
  - 必须支持 PM2 (Node.js 进程管理工具) 原生部署方式。
  - 所有数据（SQLite数据库文件）需实现持久化（如挂载 Docker 数据卷）。
- **安全性**：
  - 用户密码需进行哈希加密存储（如 bcrypt）。
  - API 请求需使用 JWT 令牌进行身份验证与权限校验。
  - 后台管理接口需进行严格的 `admin` 角色校验。
