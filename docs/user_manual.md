# 人生三万天 (Life 30,000 Days) - 用户使用手册

欢迎使用“人生三万天”应用！本手册将帮助您快速了解并上手系统的各项功能。

## 1. 注册与登录
- **访问首页**：打开系统链接后，若您尚未登录，系统会展示默认的 30,000 天倒计时。
- **注册账号**：
  1. 点击页面右上角的“注册”按钮。
  2. 填写您的**姓名**、**邮箱**、**密码**。
  3. （重要）设置您的**出生日期**。系统将根据此日期为您计算“人生三万天”的剩余天数。
  4. 点击“注册并开始”，完成注册。
- **登录**：如果您已有账号，点击“登录”，输入邮箱和密码即可进入您的专属倒计时主页。

## 2. 认识您的主页 (Home)
成功登录后，您将看到您的专属主页：
- **生命倒计时**：屏幕中央巨大的数字，是您距离三万天（约82岁）的剩余天数，提醒您珍惜时光。
- **实时时钟**：显示当前的精确时间。
- **每日金句**：页面下方会随机展示一条名言警句，给您带来启发。

## 3. 随笔记录 (Memos)
生活中总有一些瞬间值得记录。
- **查看随笔**：点击导航栏的“随笔”进入列表，可按时间线回顾您过去的记录。
- **发布新随笔**：
  1. 点击“随笔”页面中的发布输入框。
  2. 填写您的想法或发生的事情，并可选择日期。
  3. 您也可以附上一张图片（输入图片链接）。
  4. 点击“发布”即可保存。
- **管理随笔**：在随笔列表中，您可以随时对已发布的随笔进行修改或删除。

## 4. 交集人员管理 (Connections)
人生是由无数个交集组成的。
- **记录相遇**：点击导航栏的“交集人员”，点击“添加”按钮。
- **填写信息**：输入对方的姓名、出生日期等信息，保存即可。
- **查看与怀念**：在列表中，您可以看到生命中遇到的每一个人，随时可以点击查看详情或删除。

## 5. 个人设置
- **修改信息**：在导航栏点击您的头像或姓名，进入个人设置。
- **更新出生日期**：如果您在注册时填写有误，可以在这里更新出生日期，首页的倒计时将自动重新计算。
- **退出登录**：在个人设置菜单中，点击“退出登录”可安全退出当前账号。

## 6. 后台管理 (Admin Console)
*注意：本功能仅对拥有管理员（Admin）权限的用户开放。*
- **访问入口**：如果您是管理员，导航栏会显示“管理后台”入口。
- **用户管理**：可查看所有已注册的用户列表，并进行管理操作。
- **金句库管理**：您可以添加、编辑或删除系统中展示的“每日金句”。
- **系统设置**：支持切换金句的来源（例如：使用系统内置库，或调用外部的 Hitokoto 一言接口）。
